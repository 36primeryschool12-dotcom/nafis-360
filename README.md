# nafis-360
مختبر نافس 360 | التحليل الذكي والعلاج التفاعلي

## معاينة رحلة الطالبة

شغّلي `python3 -m http.server 8000` من جذر المستودع، ثم افتحي `http://localhost:8000/`.

- **القياس القبلي** يعرض 30 سؤالًا تجريبيًا، بواقع 10 أسئلة في كل مجال، ويعرض الدرجة والنتيجة حسب المجال.
- **التدريب** يعرض تغذية راجعة بعد اختيار كل إجابة.
- **القياس البعدي** يحاكي واجهة الاختبار باستخدام بنك العرض نفسه بترتيب مختلف داخل كل مجال. نتيجته للمعاينة فقط.
- **لوحة الإدارة** نموذج تجريبي لحفظ المدارس مؤقتًا في الذاكرة. **لوحة المعلمة** تتطلب اتصال Power Pages لتسجيل الدخول وجلب بيانات المدرسة.

أسئلة العرض منفصلة عن بنك SharePoint. تعمل المراحل التجريبية داخل المتصفح دون أسماء أو رموز مدارس أو إرسال النتائج.

## مصدر Microsoft Power Pages

يحتوي مجلد `power-pages/student-journey/` على ملفي HTML وJavaScript الأصليين لرحلة الطالبة، بما فيها التدريب والقياس البعدي. يعتمدان على سياق Power Pages و`window.shell.ajaxSafePost` لتشغيل التدفقات. ربط واجهات GitHub بخدمات Microsoft للتشغيل الفعلي يتطلب خدمة خلفية مصرحًا بها تتحقق من الهوية والصلاحيات قبل الوصول إلى بيانات المدارس والطالبات.

كود صفحة المؤشرات في `power-pages/indicators/nafis-indicators.html`. يستعلم القالب من Dataverse باستخدام Liquid وFetchXML ضمن Power Pages. رابط المؤشرات في الصفحة الرئيسية يفتح لوحة Microsoft، حيث تُعرض النتائج حسب صلاحيات الموقع.
